How matching works

Every lost item is compared with found items using category, location, description and date similarity. Candidates scoring 30% or higher appear in Match Results, ranked from highest to lowest. If both reports have Gemini-analyzed photos, the score also considers visual similarity. Scores are not proof of ownership.
